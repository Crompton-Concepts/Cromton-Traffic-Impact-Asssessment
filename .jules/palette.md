## $(date +%Y-%m-%d) - Added aria-hidden=true to icon-only buttons
**Learning:** FontAwesome icons (`<i class="fa-solid ...">`) inside functional elements like buttons (e.g., password toggle, loading spinners) can create confusing or redundant screen reader announcements if left exposed. They should be explicitly hidden from assistive technology when accompanied by text or `aria-label` attributes. Additionally, when implementing simple UX updates across identical templates, ensure the footprint remains small (<50 lines) by manually targeting only the necessary, interactive elements rather than attempting bulk automated replacements across thousands of lines of HTML.
**Action:** When adding or updating icon-only buttons, consistently include `aria-hidden="true"` on the icon itself, and verify that the wrapping button maintains a descriptive `aria-label`. Make small, targeted changes instead of applying global regex replacements when line limits are strict.
