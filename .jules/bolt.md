## 2024-05-24 - [Optimize Bounded Geospatial Searches with Pre-Filtering Bounding Box and Single-Pass Reduces]
**Learning:** In scenarios where we process thousands of GeoJSON points checking for nearby locations via computationally expensive trigonometric Haversine distance, passing every coordinate into `haversineDistance()` causes significant blocking and slowdown. A fast arithmetic bounding-box pre-filter can quickly eliminate >95% of candidates. Furthermore, chained `.map().filter()` operations on large arrays create significant Garbage Collection (GC) overhead by generating intermediate arrays.
**Action:** When filtering spatial datasets, implement a mathematically padded bounding box check (with antimeridian and pole safety) *before* triggering Haversine distance calculations. Refactor chained array operations (like `.map().filter()`) into a single `.reduce()` pass to prevent intermediate memory allocations.
