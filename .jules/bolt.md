## 2024-05-25 - [Spatial Bounding Box Optimization]
**Learning:** The frontend JavaScript (`app.js`) iteratively processes large GeoJSON spatial datasets, performing computationally expensive exact distance calculations using the Haversine formula on every single data point before determining if it's within a target radius. When doing unbounded global searches, this scales as O(N) with expensive trig functions.
**Action:** Implemented a pre-filtering spatial bounding box check (`isWithinBoundingBox`) that leverages simple subtraction before calling `haversineDistance`. This quickly rules out points outside a fast approximated coordinate bounding box, avoiding the Haversine trigonometric functions for the majority of the dataset. Need to ensure exact padding on the bounding box to prevent edge-case false negatives near the poles and antimeridian wrapping.
