## 2024-05-18 - Spatial filtering before heavy operations
**Learning:** `app.js` runs Haversine formula inside `.filter()` operations over `macroSitesData` entries (e.g. at lines 18792 and 19421). This recalculates Haversine for the entire dataset, which is unoptimized. We should use a fast bounding box pre-filter before calling `haversineDistance`.
**Action:** Before running expensive distance calculations inside a loop or `.filter()` over the entire spatial dataset, apply a bounding box check (using `dLat`/`dLon` thresholds) to reject distant points rapidly. Note: "When applying spatial bounding box filters in app.js to optimize performance, only apply them to bounded searches (e.g., filtering within a known radius like localCounterMatchRadiusMeters). Applying fixed bounding box limits to global unbounded searches (e.g., findBestReferencePoints) can cause false negatives for remote areas."
